# Laboratório da C2.7 (performance frontend)
Pacotes (npm, 2026-11-25): lighthouse 13.6.0, web-vitals 6.2.3 (instalado; as medições usaram PerformanceObserver direto), vite 8.3.8, rollup-plugin-visualizer 7.3.0, sharp 0.35.5, react e react-dom 19.3.1, vitest 5.1.1 (memoização). Google Chrome 157, Node 26.
- `srv.mjs`: servidor com atrasos artificiais (`ruim.html`, `bom.html`, `cls-ruim.html`, `cls-bom.html`, `inp-lento.html`, `inp-dividido.html`); `lh.mjs`: Lighthouse; `pp.mjs`: Puppeteer com PerformanceObserver; `vite-app/`: build com e sem `lazy`; `pfe7.test.jsx`: contagens de memoização. Resultados em `medicoes.txt`.
- Reexecutar: instalar os pacotes numa pasta vazia (`npm pkg set type=module`), gerar `pub/hero.jpg|webp|avif` com sharp (gradiente 1200x630), iniciar `node srv.mjs` e rodar `node lh.mjs` e `node pp.mjs`.
Limitações: medições de laboratório (um navegador, uma máquina, throttling simulado do Lighthouse); a variação entre execuções foi registrada (TBT de 0 a 90 ms); o gradiente sintético não representa o tamanho de fotos reais nos formatos; `web-vitals` (campo), CrUX, RUM real, Lighthouse CI, React Compiler, fontes e `font-display` não foram executados.
