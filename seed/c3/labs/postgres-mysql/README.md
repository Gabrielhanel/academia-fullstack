# Laboratório do C3.3 — PostgreSQL e MySQL: operação e desempenho
- Ambiente (2026-11-25): PostgreSQL 17.12 (`postgres:17`, contêiner `c3-pg17`, 127.0.0.1:55432), MySQL 8.4.13 (`mysql:8.4`, contêiner `c3-mysql84`, 127.0.0.1:53306), réplica PostgreSQL em `c3-pg17-replica` (rede `c3net`). Imagens oficiais do Docker Hub. Padrões de configuração (shared_buffers 128MB, work_mem 4MB, max_connections 100).
- Arquivos: `pg-indices.sql` / `saida-pg-indices.txt` (500 mil pedidos, EXPLAIN ANALYZE, B-tree, composto, cobertura, parcial, GIN, trigramas, GiST), `pg-otimizacao.sql` / `saida-pg-otimizacao.txt` (junções, estatísticas defasadas, OFFSET x chave, custo de escrita, VACUUM, partições), `pg-extra.sql` / `saida-pg-extra.txt`, `pg-comparacao.sql` / `saida-pg-comparacao.txt` e `mysql-comparacao.sql` / `saida-mysql-comparacao.txt` (diferenças de dialeto lado a lado), `mysql-indices.sql` / `saida-mysql-indices.txt`, `pg-tipos.sql` / `saida-pg-tipos.txt` e `mysql-tipos.sql` / `saida-mysql-tipos.txt`, `saida-backup-replicacao.txt` (pg_dump/restore em três tentativas, mysqldump, pg_basebackup e réplica por streaming).
- Como reproduzir: subir os contêineres (comandos na aula pgm-01) e executar cada `.sql` com `docker exec -i c3-pg17 psql -U postgres -q -f - < arquivo.sql` (PostgreSQL) ou `docker exec -i c3-mysql84 mysql -uroot -plab --table --force --default-character-set=utf8mb4 < arquivo.sql` (MySQL). O gerador de dados usa `setseed(0.42)`; contagens aleatórias (por exemplo, 37 linhas do cliente 123) podem variar em outra execução.
- Limitações: tempos de uma só máquina e de um contêiner (com cache quente/frio misturado); a primeira execução de `pg_basebackup` sem `-c fast` não terminou em 5 minutos e foi interrompida (causa provável: espera de checkpoint; não confirmada). Nada de produção foi tocado.
- Não executado: replicação e particionamento do MySQL, PITR, pg_stat_statements, PgBouncer, failover, BRIN, índice hash, MariaDB.
- Limpeza ao fim da C3: `docker rm -f c3-pg17 c3-mysql84 c3-pg17-replica && docker network rm c3net`.
