== 2. verificação com janela e proteção contra reuso
código do passo atual: aceito (deslocamento 0)
mesmo código de novo: recusado: código já usado (reuso)
código do passo anterior (relógio atrasado 30 s) para outro usuário: aceito (deslocamento -1)
código de 3 passos atrás (90 s): recusado
código errado: recusado
