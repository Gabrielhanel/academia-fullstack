# Laboratório: Python para desenvolvedores (curso C4.8)

- Ambiente: **Python 3.14.4** (venv, GIL ativo, método de início de processos `forkserver` no Linux), FastAPI 0.165.0, Starlette 1.10.0, Pydantic 2.14.4, uvicorn 0.54.0, httpx 0.28.1, pytest 9.2.0 e mypy 2.4.1 (versões em `requirements.txt`), em 2026-11-25; Node.js 26.13.1 só como cliente de carga.
- Reexecutar: `python3 -m venv .venv && . .venv/bin/activate && pip install -r requirements.txt` e depois `python tipos.py`, `python funcoes.py`, `cd auto && python -m pytest -q` (volte à raiz), `python automacao.py`, `python testa_fastapi.py`, `python tipagem.py`, `python assincrono.py`; para a carga: `python -m uvicorn app_fastapi:app --port 59301 --log-level warning &` e `node carga-cliente.mjs` (o `carga_fastapi.py` é a primeira versão, com cliente httpx em Python).
- Scripts e saídas: `tipos.py` (tipagem dinâmica, números, identidade, argumento padrão mutável, cópias, estruturas, compreensões, strings); `funcoes.py` (argumentos, closures, decoradores, geradores, lru_cache, pacotes e módulos); `automacao.py` + `auto/relatorio.py` + `auto/test_relatorio.py` (script com argparse, pathlib, csv, json e logging, testado com pytest: 6 testes; subprocess e injeção); `app_fastapi.py`, `testa_fastapi.py`, `carga-cliente.mjs` (FastAPI: validação 422, response_model, dependências, OpenAPI e as três formas de "esperar 50 ms"); `tipagem.py` + `tipagem/` (mypy --strict em arquivos correto e com 6 erros; anotações não verificadas em execução; Pydantic); `assincrono.py` (gather, TaskGroup, timeout, to_thread, GIL com threads e processos).
- Correções e achados: o primeiro teste de carga usou um cliente httpx em Python e ficou limitado por ele (77,1; 72,0 e 19,0 req/s nas três rotas); foi refeito com um cliente Node em outro processo (261,0; 197,1 e 18,9 req/s); no Python 3.14, `ProcessPoolExecutor` usa `forkserver` por padrão no Linux, que reimporta o módulo principal (sem `if __name__ == '__main__':` o script falha com RuntimeError e duplica a saída); `fastapi.testclient` emite um aviso de depreciação do uso do httpx (a Starlette recomenda `httpx2`); no exemplo do argumento padrão mutável a primeira versão imprimia a mesma lista duas vezes (agora sequencial); o rótulo de `-X importtime` foi retirado da medição de importação.
- Limitações: uma máquina e uma execução (a mediana de 5 a 7 quando indicado); os tempos de CPU (13,5 s sequencial) são desta máquina de 8 núcleos; o `lru_cache` e as compreensões mostram comportamento de CPython, não de outras implementações; o build com GIL desativado (free-threaded) **não** foi executado. Não executados: Django/Flask, SQLAlchemy, Celery, pyright, Ruff/Black, Poetry/uv, empacotamento e publicação (pip/PyPI), Docker de aplicações Python, Jupyter e as bibliotecas científicas (NumPy, pandas).
